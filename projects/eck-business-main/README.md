# ECK 기업교육 GitHub Pages 업로드 파일

## 업로드 방법

1. 이 폴더 안의 `index.html`과 `images` 폴더를 함께 GitHub 저장소 최상단에 업로드합니다.
2. 업로드 후 저장소 구조가 아래와 같은지 확인합니다.

```text
eck-business/
├── index.html
└── images/
    ├── languages-55.png
    ├── language-content.png
    ├── instructor-pool.png
    ├── instructors.png
    ├── sample-learner.png
    ├── sample-dashboard.png
    ├── sample-admin.png
    ├── learning-content.png
    ├── clients-public.png
    ├── clients-corporate-01.png
    ├── clients-corporate-02.png
    ├── clients-corporate-03.png
    ├── eck-logo.png
    ├── eck-logo-white.png
    ├── feature-01.png ~ feature-04.png
    └── process-01.png ~ process-04.png
```

3. GitHub의 `Settings → Pages`에서 `main / (root)`로 배포합니다.

## 이번에 로컬 파일로 연결한 이미지

- 55개 언어 대표 이미지
- 언어별 강좌·교재 이미지
- 온라인 강사풀 및 강사진 이미지
- 학습페이지 미리보기 4장
- 고객사 로고 이미지 4장
- 상단·모바일 메뉴 및 하단 ECK 로고
- ‘무엇이 다른가’ 아이콘 4개
- 도입 절차 아이콘 4개

## 아직 외부 주소를 사용하는 이미지

첨부되지 않은 아래 이미지는 기존 외부 주소를 유지합니다.

- 강좌 썸네일 이미지

이 이미지들까지 저장소에 포함하면 외부 이미지 서버에 의존하지 않는 완전한 독립형 페이지가 됩니다.
